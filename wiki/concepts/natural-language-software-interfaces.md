[零基础｜搭建基于私域数据的ChatGPT]({{< relref "/wiki/sources/build-chatgpt-with-private-data.md" >}}) argues that large language models make natural language a new interface for accessing and manipulating software data. Instead of navigating only through graphical controls, users can ask questions or describe desired outcomes directly.

The source connects this interface shift to a development shift: more application behavior can be specified as prompts that describe the desired role, context, and output, while frameworks assemble the supporting retrieval and tool-use steps.
