## Definition
[[HeuristicEvaluation]] is an expert UX evaluation method where reviewers inspect an interface against general usability principles such as feedback, consistency, clear language, error recovery, and help.

## Current Synthesis
In RORIRI's UX report article, heuristic evaluation is the design-element layer beneath cognitive walkthrough findings, subjective ratings, and behavior logs. It asks what the software provides or fails to provide, then explains how those design properties become cognitive load. In the Jamovi case, weak diagnosis/recovery and help documentation explain why users repeated failed drag operations without understanding the data-type problem.

## Key Claims
- Heuristic evaluation inspects the interface itself rather than directly observing users.
- Expert evaluators can identify design properties that users may experience only as confusion or repeated failure.
- Heuristic findings can serve as upstream causes in a UX report's explanatory chain.
- The method is strongest when combined with user behavior and subjective data rather than used as the only evidence.
- Heuristic evaluation should be adapted to the research question instead of becoming a template-driven checklist.

## Evidence
- Method role: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] describes experts checking the software against Nielsen-style heuristic principles after performing a cognitive walkthrough.
- Design layer: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] places heuristic results before cognitive load in the four-layer explanation.
- Jamovi diagnosis: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] reports high problems in diagnosis/recovery and help documentation, which explains why the system failed to guide users after drag errors.
- Mixed-method qualification: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] stresses that the same four layers can be rearranged or replaced if a different research design requires it.

## Counterevidence & Qualifications
Experts have blind spots because professional knowledge can make it hard to recover a novice user's uncertainty. The source therefore treats heuristic evaluation as one perspective among others, not as a substitute for user observation.
