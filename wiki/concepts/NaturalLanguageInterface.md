## Definition
[[NaturalLanguageInterface]] is a software interaction pattern where users retrieve information, operate data, or request actions through ordinary language rather than only through graphical controls or formal commands.

## Current Synthesis
The source argues that large models make natural language a new software interface layer. Instead of requiring users to navigate many screens or encode every process procedurally, applications can let users describe what they want, retrieve or manipulate underlying data, and receive generated outputs. The article connects this shift to private-data chatbots and to prompt-centered development of AI application behavior.

## Key Claims
- Natural language can become a primary way to access and operate software data.
- Generative AI features are expected to become common additions to existing software products.
- Private-data chatbots demonstrate natural-language querying over user-held corpora.
- Prompt-centered development describes desired outcomes and roles more directly than traditional procedural code for some core behaviors.
- Natural-language interfaces expand user choice rather than necessarily replacing graphical interfaces.

- Data operation: [[ling-ji-chu-da-jian-ji-yu-si-yu-shu-ju-de-chatgpt]] says users can access and operate underlying data through natural language instead of only through graphical clicking.
- Product adoption: [[ling-ji-chu-da-jian-ji-yu-si-yu-shu-ju-de-chatgpt]] cites traditional software adding generative-AI capabilities.
- Private-data example: [[ling-ji-chu-da-jian-ji-yu-si-yu-shu-ju-de-chatgpt]] demonstrates asking Chinese questions over an English private dataset.
- Prompt development: [[ling-ji-chu-da-jian-ji-yu-si-yu-shu-ju-de-chatgpt]] describes telling the model the role and function it should provide as a result-oriented development mode.

## Counterevidence & Qualifications
The source does not address when graphical interfaces remain superior, how to avoid ambiguous instructions, how to expose state and provenance, or how teams should evaluate reliability in natural-language workflows.
