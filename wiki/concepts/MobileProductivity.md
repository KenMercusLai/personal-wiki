## Definition
[[MobileProductivity]] is the reshaping of work software and enterprise workflows as cloud and mobile devices absorb tasks once associated with PCs, keyboards, mice, and office suites.

## Current Synthesis
The sources argue that productivity and creation should not be equated with specific legacy tools such as the mouse, keyboard, Excel, PowerPoint, desktop file systems, or complex windows. Those tools may remain important for some users and workloads, but billions of others may write, photograph, edit, share, communicate, and work through cloud software and mobile-centered devices with different interaction models. Evans's 2017 segmentation preserves a relatively small class of precision-heavy professional software while arguing that most PC activity did not require the full PC interface. Sinofsky adds the enterprise-product implication: mobile platforms bring stronger security architecture and rapidly improving data-management capability, but teams should redesign work for the new style rather than use inability to reproduce every familiar PC task as a veto. The deeper productivity question is the connective tissue of a company: the verbs and workflows that move work along.

## Key Claims
- "Real work" should not be defined by legacy PC input devices or office-suite formats.
- Some power users will keep big screens, keyboards, spreadsheets, and presentations for a long time.
- Mobile and cloud software can reshape work for broader populations beyond core office-tool users.
- Enterprise strategy should focus on workflow verbs and connective tissue, not only documents or operating systems.
- Mobile enterprise adoption is strongest when products exploit mobile security, management, and interaction models rather than imitate every desktop workflow.
- Mobile creation already includes writing, photography, video, sharing, and communication; professional desktop software is a boundary case rather than the definition of creation.

## Evidence
- Legacy-tool critique: [[16-mobile-theses-benedict-evans]] asks whether typing or making presentations is the job or just a tool for getting work done.
- User segmentation: [[16-mobile-theses-benedict-evans]] says mouse, keyboard, Excel, and PowerPoint will linger for many core users but not necessarily for billions.
- Cloud shift: [[16-mobile-theses-benedict-evans]] argues productivity software will move to the cloud and onto mobile devices.
- Connective tissue: [[16-mobile-theses-benedict-evans]] says the important layer is the verbs that move company work along.
- Enterprise platform case: [[hallway-debates-a-2016-product-manager-discussion-guide-learning-by-shipping]] argues that mobile security, device-data management, and Apple/Google enterprise investment make new work scenarios increasingly viable.
- Installed-base qualification: [[hallway-debates-a-2016-product-manager-discussion-guide-learning-by-shipping]] acknowledges that software development and many other workloads can remain desktop-centered for a long time without invalidating forward-looking mobile investment.
- Creation evidence: [[creation-and-consumption-benedict-evans]] identifies writing, photography, video, sharing, games, and communication as active mobile creation.
- Workload segmentation: [[creation-and-consumption-benedict-evans]] estimates that sophisticated professional applications accounted for a small minority of PC use while routine web, email, and business-process work needed fewer PC-specific affordances.
- Usability mechanism: [[creation-and-consumption-benedict-evans]] argues that simpler mobile abstractions make capabilities usable by people who did not master PC workflows.

## Counterevidence & Qualifications
The sources are directional 2015–2017 arguments and do not specify which jobs can fully leave PC workflows, which require large-screen precision, or how later enterprise adoption, accessibility, compliance, device-management, and security evidence changes the conclusion. Evans's professional-user estimate is approximate and partly overlap-sensitive, while broad claims about ease do not substitute for disability-access or mobile-only disadvantage analysis. Mobile-specific redesign can also fragment workflows when cross-device continuity is weak.

## What Changed
- Reframed mobile creation as already present in writing, images, video, sharing, and communication rather than a future PC imitation.
- Added Evans's distinction between mainstream work and the smaller precision-heavy professional software segment.
- Added capability accessibility as the mechanism by which simpler workflows broaden productive participation.
