## Definition
[[UXResearchInformationDesign]] is the practice of designing a research report so that observations, methods, measures, contradictions, and conclusions form an interpretable explanatory structure instead of a loose pile of data.

## Current Synthesis
RORIRI frames UX research as an information space that must be deliberately organized. Data is only raw observation until the researcher connects it through comparisons, visualizations, method choices, causal relations, and argument order. A useful report therefore resembles an evidence chain: a central question is decomposed into subquestions, each subquestion receives method-appropriate evidence, and the report explains why conflicting findings can belong to the same system.

## Key Claims
- UX data does not explain itself; researchers decide which relationships become visible.
- Reporting quality depends on connecting data into argument, not merely choosing good research methods.
- Contradictory data can become useful when the report identifies which layer each dataset describes.
- Visual and statistical techniques such as heatmaps, stacked bars, Sankey flows, clustering, ANOVA, regression, and chi-square tests can help data explain other data.
- The best framework is not a fixed template but a source-specific structure discovered from the research question and evidence.

## Evidence
- Raw data limit: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] criticizes reports that paste observations and surface interpretation into slides while transferring the integration burden to readers.
- Connection techniques: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] lists heatmaps, grouped stacked bars, Sankey-style flow charts, clustering, ANOVA, regression, and chi-square tests as ways of making data relate to other data.
- Argument chain: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] borrows from academic writing: a main question breaks into subquestions, and each subquestion receives evidence that leads toward the conclusion.
- Framework discovery: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] says the four-layer model emerged from conflicting Jamovi study data and should not be copied mechanically as a universal template.

## Counterevidence & Qualifications
The source is a practitioner essay and single case explanation. It argues for flexible report architecture but does not evaluate whether a particular visual form or report order improves stakeholder decisions across different UX research teams.
