应用与网页的主屏测试把复杂的 App 与 Web 技术争论还原成用户入口问题。Benedict Evans 承认，原生应用、移动网页、浏览器能力、Google 的 Chrome 策略和应用发现之间有很多技术细节，但对多数品牌、开发者或出版者来说，核心问题更直接：用户是否愿意让这个服务占据手机主屏上的一个位置。

这个测试强调的是频率、身份和入口价值。需要高频使用、强通知、深系统能力或明确用户关系的服务，更可能值得拥有独立 App；低频、搜索驱动或一次性任务，则未必能通过安装成本和主屏占位的门槛。

因此，App 与 Web 的选择不只是工程实现选择，也是分发策略选择。它要求产品团队判断自己在用户生活中的真实位置，而不是只比较原生 API 和网页能力。
