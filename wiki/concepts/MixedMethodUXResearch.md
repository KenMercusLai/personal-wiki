## Definition
[[MixedMethodUXResearch]] combines multiple UX research methods so that user behavior, subjective experience, expert inference, and interface design properties can explain one another.

## Current Synthesis
RORIRI's Jamovi example treats mixed methods as a way to inspect different layers of one usability problem. Observation and think-aloud reveal what users do, questionnaires capture how they report the experience, PURE-style cognitive walkthroughs infer what users must understand at each step, and heuristic evaluation inspects the interface principles that make those cognitive demands higher or lower. The value comes from aligning methods by explanatory role rather than simply increasing method count.

## Key Claims
- Method selection is a resource tradeoff: researchers choose the smallest useful set rather than every available method.
- User behavior and subjective questionnaires answer different questions and should not be collapsed into one evidence type.
- Expert methods add value because trained evaluators can infer cognitive demands and design-principle violations that users may not articulate.
- Mixed-method evidence may appear contradictory until each method is placed at the proper explanatory layer.
- The same method stack should not be treated as a universal recipe; methods can be replaced if the report preserves a coherent logic.

## Evidence
- Resource choice: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] describes choosing observation plus think-aloud before adding questionnaires and expert methods because time and resources are limited.
- User evidence split: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] distinguishes behavior data from observation and subjective data from post-task standardized questionnaires.
- Expert evidence split: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] uses PURE cognitive walkthroughs for inferred cognition and heuristic evaluation for design-principle quality.
- Contradiction handling: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] resolves Jamovi conflicts by showing that a hard cognitive prerequisite can produce many later errors in a step experts scored as easy.

## Counterevidence & Qualifications
The article's method mix is tailored to a software usability study. Field research, service research, diary studies, card sorting, interviews, or log analysis could require a different explanatory architecture.
