## Definition
[[ProgrammingLiteracy]] is the broadly distributed ability to express and run computational logic for personally meaningful work, without requiring everyone to become a professional software developer.

## Current Synthesis
The source uses ordinary reading and writing as an analogy: universal literacy does not imply universal authorship, and programming literacy need not imply professional engineering. Its claim is about agency in a world increasingly mediated by computers—people should be able to manipulate some of the systems and information that shape their work and lives rather than remaining limited to fixed software behavior.

The proposed route is task-centered rather than language-centered. People are more likely to learn computational ideas when an integrated environment helps them accomplish an existing goal and makes state, logic, and results inspectable. That broad-access aspiration is compatible with a deeper educational boundary: usable tools can create motivation and early success, but independent competence still requires reasoning, debugging, retention, feedback, and transfer.

Coding agents radically lower the execution barrier envisioned by end-user computing: people outside CS can now build useful software for their own disciplines without first mastering a conventional language sequence. That expands agency, but it also weakens the link between successful output and literacy. A person may direct a model to produce a working site while remaining unable to explain, verify, maintain, or adapt it beyond the model's capability boundary.

## Key Claims
- Programming literacy seeks practical computational agency rather than universal professional-software expertise.
- Relevance to an existing goal can motivate learning more effectively than programming presented as an end in itself.
- Tool design is part of literacy access because setup burden and expert-oriented choices determine who can begin.
- Domain-specific vocabulary can let learners express useful operations before mastering general-purpose abstractions.
- Visual state and immediate results can make program behavior easier to inspect and revise.
- Broad access should not be confused with proof of deep understanding, independent transfer, or safe production engineering.
- Coding agents can expand non-specialists' practical reach while making explanation, verification, and adaptation central tests of literacy.

## Evidence
- Literacy analogy: [[end-user-computing-the-truant-haruspex-medium]] compares practical programming ability with ordinary reading and writing rather than specialist authorship.
- Motivation and relevance: [[end-user-computing-the-truant-haruspex-medium]] argues that learners care about programming when it advances goals in their own lives.
- Access conditions: [[end-user-computing-the-truant-haruspex-medium]] identifies integrated setup and task-oriented tools as barriers and uses spreadsheets as the positive case.
- Proposed contexts: [[end-user-computing-the-truant-haruspex-medium]] suggests social applications, home automation, and games as task-centered entry points but provides no outcome data.
- Agent-enabled reach: [[ai-shi-dai-de-ben-ke-cs-jiao-yu-sui-xiang-jie-ge-de-jiao-xue-yun-wei-bian-cheng-diao-ban-zi-xiao-bi-ji]] reports non-CS students building field-relevant software rapidly, while warning that AI-dependent users may not understand internals and remain bounded by model capability.

## Counterevidence & Qualifications
The printing-press comparison is an analogy, not evidence that programming will spread, matter, or be taught in the same way as textual literacy. Neither source specifies a validated minimum competency, accessibility standard, safety boundary, or maintenance model. The CS-education essay's rapid website example is anecdotal and does not establish independent skill. The existing [[ProgrammerMindset]] synthesis also challenges any interpretation that better tools alone make people independently capable programmers.

## What Changed
- Created a bounded definition of programming literacy as practical computational agency rather than professional identity.
- Combined the source's task-centered access thesis with the wiki's existing transfer and reasoning qualifications.
- Added coding agents as a mass-access mechanism while separating useful output from explainable, transferable competence.
