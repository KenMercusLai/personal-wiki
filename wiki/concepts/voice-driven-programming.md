Voice-driven programming 是把语音识别接入开发任务输入框，让开发者在不方便打字时也能提交自然语言需求。胡渊鸣把它用于自己的 Claude Code 管理系统，使手机、走路、乘车和睡前等场景中的想法可以直接进入开发队列。

在这篇文章中，语音输入解决的是 agentic coding 的上游瓶颈：当 AI 执行速度提高后，人的打字速度和捕捉想法的能力会成为限制。语音让作者更快把产品想法、功能需求和问题描述交给 AI 执行。
