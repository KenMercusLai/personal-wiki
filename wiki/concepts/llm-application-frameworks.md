[零基础｜搭建基于私域数据的ChatGPT]({{< relref "/wiki/sources/build-chatgpt-with-private-data.md" >}}) describes LangChain as a middle-layer product for building applications on top of large language models. The source places it alongside GPT-Index, Semantic Kernel, and Leap AI as tools that help developers connect models to data, APIs, and domain workflows.

In the source's framing, these frameworks matter because large-language-model applications repeatedly need similar building blocks: model calls, prompt templates, chain composition, conversation memory, agents, embeddings, and vector-store integrations.
