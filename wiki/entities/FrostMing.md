## Overview
[[FrostMing]] is a software practitioner and blogger represented here by an experiment that turned [[Bub]] into a minimal, self-bootstrapping Telegram agent.

## Current Profile
The available source presents Frost Ming as both implementer and conceptual advocate. Working with [[PsiACE]], he first reproduced [[OpenClaw]]-like messaging behavior through ordinary code, then used Bub's ability to create Skills and small runtime artifacts to argue for [[AINativeAgentArchitecture]]: a deliberately tiny host that lets the agent manage more of its own capability surface.

## Key Characteristics
- Experiments with coding agents as the substrate for persistent messaging bots.
- Advocates a reasoning core with shell, file access, and agent-managed Skills over a feature-heavy framework.
- Uses Docker startup behavior and one-shot agent commands to build a self-bootstrapping runtime.
- Treats natural-language direction and emergent agent behavior as the desired human control surface.
- Frames the work through an explicitly anthropomorphic metaphor of an agent growing from a seed into a living system.

## Evidence
- Project role: [[chuang-zao-yi-zhi-long-xia-xu-yao-xie-shi-me-frosts-blog]] describes Frost Ming initiating the OpenClaw reproduction and collaborating with PsiACE on Bub.
- Architecture position: [[chuang-zao-yi-zhi-long-xia-xu-yao-xie-shi-me-frosts-blog]] argues for removing framework-owned messaging behavior in favor of agent-created Skills and startup code.
- Runtime mechanism: [[chuang-zao-yi-zhi-long-xia-xu-yao-xie-shi-me-frosts-blog]] describes the startup-script fallback protocol, Docker process management, and one-shot agent invocation.
- Control philosophy: [[chuang-zao-yi-zhi-long-xia-xu-yao-xie-shi-me-frosts-blog]] says requirements should be issued through prompts and that the agent should decide whether and how to comply.

## Qualifications
The profile rests on one self-authored article about a short experiment. It does not establish the broader scope of Frost Ming's work, independently verify the deployment, or measure its reliability, security, cost, or long-term evolution. The source's preference for unread agent-written code and prompt-only behavioral control is a design position, not evidence that external verification and enforcement are unnecessary.
