## Overview
[[TheArchive]] is a macOS plain-text note application used in the source as the permanent-note layer of a Zettelkasten workflow.

## Current Profile
The source presents The Archive as a fast interface over Markdown files stored in a flat structure. It creates stable timestamp identifiers, supports bracketed note links and search, and leaves the files readable outside the application. Chaperon values the product because it reduces capture and retrieval friction without prescribing a complete knowledge-management doctrine.

## Key Characteristics
- Stores notes as plain Markdown text files.
- Supports timestamp-based identifiers and direct note links.
- Uses search and contextual terms across a mostly flat archive.
- Keeps storage portable enough for synchronization and access by other text-capable tools.
- Serves permanent notes rather than the source's visual-mapping or long-form-writing stages.
