Cursor Agent 是胡渊鸣文章中提到的另一个 agentic coding 工具。作者曾在带 4090 GPU 的 Ubuntu Desktop 上使用 Cursor Agent，并称自己用它在数小时内重新设计了一套 GPU DSL。

在后续 CEO 支持系统项目中，作者转向 Claude Code，主要原因是 Claude Code 在远程无图形界面和手机访问场景下更适合被持续调度。
