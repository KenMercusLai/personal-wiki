Taichi programming language 是胡渊鸣在文章中介绍个人经历时提到的项目。作者称自己在 MIT 博士期间开发了 Taichi 编程语言及其编译器，目的是方便用户编写 GPU 上的高性能物理仿真程序。

文章还提到，作者曾想做 Taichi 2.0 来解决团队训练 3D foundation model 时的性能问题，后来把 Cursor Agent 视为推动这类工作的高杠杆工具。
