Tim Berners-Lee 在来源中作为 HTTP 起源的关键人物出现。

来源：[陈皓 - HTTP的前世今生]({{< relref "/wiki/sources/chen-hao-http-history.md" >}})

来源称他是欧洲核子研究委员会 CERN 的英国工程师，并将 HTTP 与 WWW 的发明归于他。这个人物条目在当前知识库中主要用于连接 HTTP 协议演进、Web 基础设施和 CERN 这一机构背景。
