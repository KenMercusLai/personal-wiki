## Overview
[[LarryEllison]] appears as Oracle's chairman publicly arguing that Amazon and other major customers were not truly moving away from Oracle Database for mission-critical workloads.

## Current Profile
The CNBC source uses Ellison as the main Oracle-side public voice in the Amazon-Oracle rivalry. In a December earnings-call remark cited by an analyst, Ellison said Amazon had recently given Oracle another $50 million for Oracle database and related technologies. In a 2016 analyst meeting, he argued that Oracle's major database customers could not run mission-critical workloads at Amazon and would instead move databases to Oracle's own cloud services.

## Key Characteristics
- Oracle chairman speaking publicly about customer retention and database superiority.
- Used Amazon's continued Oracle spending to dispute reports of AWS-driven migration.
- Claimed Amazon's cloud was not ready for mission-critical Oracle database workloads.

## Evidence
- Amazon spend claim: [[cnbc-amazon-plans-to-move-off-oracle-software-by-early-2020]] quotes Ellison saying Amazon had given Oracle another $50 million in a quarter.
- Competitor-retention claim: [[cnbc-amazon-plans-to-move-off-oracle-software-by-early-2020]] quotes Ellison saying competitors continued to invest in and run their businesses on Oracle.
- Mission-critical claim: [[cnbc-amazon-plans-to-move-off-oracle-software-by-early-2020]] quotes Ellison saying Oracle database customers could not run mission-critical workloads at Amazon.

## Qualifications
The source presents Ellison's remarks as competitive advocacy during a public cloud rivalry. It does not independently verify the technical limits of AWS or the later migration outcome.
