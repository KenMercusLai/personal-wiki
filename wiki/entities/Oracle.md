## Overview
[[Oracle]] appears as the incumbent proprietary database vendor that Amazon planned to leave as Amazon's AWS cloud business became a direct enterprise-computing rival.

## Current Profile
The CNBC source frames Oracle as a longtime Amazon supplier whose core database business faced pressure from cloud migration and AWS database alternatives. Amazon's planned exit from Oracle databases was presented as another blow because some of Amazon's core shopping systems still depended on Oracle in 2018, while AWS was growing quickly and offering competing services such as [[AmazonAurora]] and Database Migration Service.

Oracle's response emphasized continuity and product superiority: its spokesperson said Amazon had spent hundreds of millions of dollars on Oracle technology, including $60 million about a year earlier, and argued that AWS lacked database technology comparable to Oracle Database. [[LarryEllison]] also used earnings-call and analyst-meeting remarks to reject the idea that major Oracle customers, including Amazon, could move mission-critical workloads to AWS.

## Key Characteristics
- Incumbent enterprise database vendor with proprietary database software used by Amazon's core shopping systems.
- Became a direct rival to Amazon as cloud workloads moved away from traditional data centers.
- Defended its database position by pointing to Amazon spending and claiming AWS database inferiority.
- Faced competitive pressure from AWS services such as Amazon Aurora and Database Migration Service.

## Evidence
- Amazon dependency: [[cnbc-amazon-plans-to-move-off-oracle-software-by-early-2020]] says parts of Amazon's core shopping business still relied on Oracle in 2018.
- Migration pressure: [[cnbc-amazon-plans-to-move-off-oracle-software-by-early-2020]] says Amazon planned to be fully off Oracle proprietary database software by the first quarter of 2020.
- Product dispute: [[cnbc-amazon-plans-to-move-off-oracle-software-by-early-2020]] quotes Oracle's statement that AWS lacked database technology close to Oracle Database.
- Customer-spend defense: [[cnbc-amazon-plans-to-move-off-oracle-software-by-early-2020]] reports Oracle saying Amazon had spent hundreds of millions of dollars on Oracle technology.
- Cloud-market weakness: [[cnbc-amazon-plans-to-move-off-oracle-software-by-early-2020]] says Oracle had failed to gain notable cloud infrastructure share and had stopped disclosing cloud-services revenue separately.

## Qualifications
This is a 2018 CNBC report and captures Oracle's position in one competitive moment. It does not establish the final outcome of Amazon's migration, later Oracle cloud performance, later database product capabilities, or current customer adoption.

## What Changed
- Created Oracle as the incumbent database and cloud rival in the Amazon migration source.
