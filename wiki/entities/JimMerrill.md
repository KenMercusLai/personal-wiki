## Overview
[[JimMerrill]] is a Riot Games engineer who wrote about automated testing for [[LeagueOfLegends]] under the handle Anodoin.

## Current Profile
In the source, Merrill serves as tech captain for the BVS-Dev team, which builds automated-testing tools and helps game teams write better tests. His account frames game test automation as both a developer-efficiency system and a player-quality system: fast CI feedback reduces late defects, while automation frees quality analysts for more creative and preventive testing.

## Key Characteristics
- Tech captain for the [[BuildVerificationSystem]] development team.
- Focused on automation for the in-game League of Legends experience.
- Presents test infrastructure as a way to improve developer feedback and reduce player-facing bugs.
- Emphasizes stable, approachable test-writing patterns for less-technical developers.

## Evidence
- Role and scope: [[automated-testing-for-league-of-legends-riot-games-technology]] identifies Merrill as the BVS-Dev tech captain focused on in-game test automation.
- Developer efficiency: [[automated-testing-for-league-of-legends-riot-games-technology]] says automation reports within about an hour and bugs found by automation are resolved faster.
- Test-writer usability: [[automated-testing-for-league-of-legends-riot-games-technology]] says BVS hides artifact gathering and workspace setup so tests can be expressed through a few arguments and linear instructions.
