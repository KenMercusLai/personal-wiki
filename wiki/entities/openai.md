OpenAI 是胡涂说文章中大模型时代的代表性公司。来源说明，ChatGPT 发布后，大模型和 AIGC 能力成为全球热门技术，也让人们看到通用人工智能和智能化工作方式的可能。

来源：[胡涂说 - 银弹飞过先锋大厦]({{< relref "/wiki/sources/hutusi-silver-bullet-software-engineering-history.md" >}})

文章标题中的“先锋大厦”指向 OpenAI 在旧金山的总部所在地。作者用这一意象连接 Brooks 的“没有银弹”论题，并表达自己的判断：大模型可能成为软件开发的银弹。

在这篇来源中，OpenAI 的意义不是公司史本身，而是 ChatGPT 作为大模型应用进入软件开发实践后，引发了对传统软件工程边界的重新判断。

来源 [深思圈的私域数据 ChatGPT 教程]({{< relref "/wiki/sources/shensiquan-private-data-chatgpt-langchain.md" >}}) 则从应用搭建角度使用 OpenAI。教程要求用户创建 OpenAI API key，并通过 LangChain 调用 OpenAI Embeddings，把上传的私域文本转成向量后写入 FAISS；示例测试数据也取自 OpenAI 的百科资料，用来对比接入外部数据前后的问答效果。
