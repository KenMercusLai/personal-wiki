## Overview
[[JaniMustonen]] is the author of the prognst blog post [[blog-jani-mustonen-prognst-the-mindset-of-a-programmer]], which argues that learning programming requires cultivating a precise reasoning mindset.

## Current Profile
The available source presents Mustonen as a programming writer concerned with the beginner gap between code that experienced programmers read fluently and code that newcomers treat as opaque snippets. His emphasis is pedagogical: learners need to understand what each statement does, and teachers need to teach the mental model behind programming rather than only the language surface.

## Key Characteristics
- Writes about programming learning from the perspective of tacit expert fluency.
- Treats copy-paste coding as useful only when paired with active study and modification.
- Emphasizes reasoning about code behavior as the core of programming education.

## Evidence
- Tacit expert fluency: [[blog-jani-mustonen-prognst-the-mindset-of-a-programmer]] says experienced programmers can read code almost subconsciously and may miss why beginners struggle.
- Copying with study: [[blog-jani-mustonen-prognst-the-mindset-of-a-programmer]] distinguishes learning from copied snippets by understanding and modifying them from merely assembling broken pieces.
- Reasoning focus: [[blog-jani-mustonen-prognst-the-mindset-of-a-programmer]] advises teachers to teach how to reason about programming instead of only the language.
