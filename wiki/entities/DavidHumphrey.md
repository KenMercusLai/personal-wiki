## Overview
[[DavidHumphrey]] is the author of the Medium essay "402: Payment Required," which argues for browser-mediated payment infrastructure as an alternative to implicit ad-funded web exchange.

## Current Profile
Within this wiki, Humphrey appears as a web commentator responding to the iOS 9 ad-blocking debate. He frames ad blocking as a chance to rethink the web's economic defaults, arguing that trusted user agents should help users pay for content and services instead of leaving sites to choose between advertising, custom paywalls, and blocked access.

## Key Characteristics
- Connects web advertising debates to protocol and browser design.
- Uses urban advertising law, mobile app stores, and streaming subscriptions as analogies for web payment infrastructure.
- Treats browsers as trusted user agents that could safely broker cross-site purchases.
- Calls for browser vendors, especially [[Mozilla]], to experiment beyond a render-versus-block model.
