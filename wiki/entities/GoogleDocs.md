## Overview
[[GoogleDocs]] is used as a collaboration-product example where the product becomes more valuable when a user shares a document with coworkers.

## Current Profile
The virality source presents Google Docs as a product with a useful single-player mode but a stronger multi-player mode. The "Share" action is treated as the viral mechanism because collaboration both helps the original user and brings another person into the product experience.

## Key Characteristics
- Collaboration software with both solo and multi-user use.
- Uses sharing as a natural invitation surface.
- Demonstrates virality through increased utility rather than external promotion.

## Evidence
- Collaboration loop: [[9-ways-to-build-virality-into-your-product-gabor-cselle-medium]] says Google Docs becomes more powerful once a user clicks "Share" and starts collaborating with coworkers.
- Single-player qualification: [[9-ways-to-build-virality-into-your-product-gabor-cselle-medium]] notes that editing alone is possible, but additional value appears with others.
- Viral control surface: [[9-ways-to-build-virality-into-your-product-gabor-cselle-medium]] treats "Share" and "Invite people" buttons as viral mechanisms for collaboration products.

## Qualifications
The source uses Google Docs as a brief virality example and does not analyze its broader product history, monetization, or enterprise adoption.
