## Overview
[[AndyJassy]] appears as AWS CEO in the CNBC source, publicly criticizing Oracle's cloud position and pointing to AWS database-migration traction.

## Current Profile
The source places Jassy on the AWS side of a public Amazon-Oracle rivalry. After Oracle executives claimed database cost advantages, Jassy told CNBC that Oracle was far behind in cloud. He also said AWS Database Migration Service had transferred more than 80,000 databases to AWS, positioning AWS not just as compute infrastructure but as a destination for incumbent database workloads.

## Key Characteristics
- AWS executive voice in the Amazon-Oracle cloud and database rivalry.
- Criticized Oracle's cloud position in public remarks.
- Used Database Migration Service transfer volume as evidence of AWS database migration adoption.
