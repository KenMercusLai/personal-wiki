## Overview
[[Nuwanda]] is the author of the MinusX article analyzing what makes [[ClaudeCode]] feel effective and how similar design choices can be reused in other chat-based LLM agents.

## Current Profile
Within this wiki, Nuwanda appears as a practitioner-author writing from direct Claude Code use and from intercepted/logged request analysis at [[MinusX]]. The profile is source-scoped: the article presents Nuwanda as interested in practical agent design, debuggable control loops, prompt structure, tool design, and steerable user experience rather than only model capability.

## Key Characteristics
- Writes from practitioner experience with Claude Code and MinusX's own agent-building work.
- Treats simple agent architecture and debuggability as central design virtues.
- Uses Claude Code's prompts, tool traffic, and control-loop behavior as evidence for reusable agent-design heuristics.

## Evidence
- Practitioner context: [[blog-minusx-nuwanda-what-makes-claude-code-so-damn-good]] says MinusX adopted many Claude Code-inspired patterns and that the analysis comes from months of use plus intercepted request logs.
- Design stance: [[blog-minusx-nuwanda-what-makes-claude-code-so-damn-good]] argues against unnecessary multi-agent complexity and in favor of one main loop.
- Reusable heuristics: [[blog-minusx-nuwanda-what-makes-claude-code-so-damn-good]] extracts lessons around context files, XML/Markdown prompt structure, live search, tool design, todo lists, and tone control.
