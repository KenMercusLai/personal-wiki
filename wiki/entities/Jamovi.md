## Overview
[[Jamovi]] is an open-source statistics application used in RORIRI's UX research report article as the concrete usability-study object.

## Current Profile
Within this wiki, Jamovi appears as a statistics tool whose users may understand statistical concepts while still struggling with software interaction. RORIRI's case study uses Jamovi's ANOVA workflow to show how subjective ratings, behavioral errors, expert cognitive walkthroughs, and heuristic analysis can contradict each other until they are arranged into an explanatory chain.

## Key Characteristics
- Serves as a modern, open-source statistics software case rather than as the article's main theoretical subject.
- Presents a user population where statistical knowledge does not guarantee interface fluency.
- In the study example, users attempted ANOVA tasks involving variables such as `cheese_type` and `nightmare_frequency`.
- The interface produced repeated drag-and-drop errors when users failed to recognize a data-type prerequisite.
- Its feedback and help behavior is framed as insufficient for diagnosing and recovering from user mistakes.

## Evidence
- Study object: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] introduces Jamovi as a free, modern statistics tool similar in category to SPSS.
- User fit: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] notes that potential users may understand ANOVA while needing to discover where controls and variables are in the software.
- Interaction evidence: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] includes screenshots of a Jamovi ANOVA interface and an annotated drag action where a variable is moved toward a dependent-variable field while an error icon blinks.
- Design limitation: [[yong-yan-bao-gao-zhong-de-xin-xi-she-ji-yao-su-luo-li-li-de-shu-ju-zhong-xin]] reports heuristic weaknesses in diagnosis/recovery and help documentation, explaining why users repeated failed actions without understanding the underlying data-type issue.

## Qualifications
The source uses Jamovi as one study example. It does not provide a broad review of Jamovi's full feature set, current release status, accessibility quality, or comparative usability against other statistics tools.
