来源：[7 Ways to Uplevel Your Code Review Skills]({{< relref "/wiki/sources/asana-uplevel-code-review-skills.md" >}})

Asana 在这篇来源中是发布代码评审实践文章的公司。文章来自 Asana engineering 语境，作者在加入 Asana 后意识到需要提升自己的 code review 技巧，并总结了团队可以讨论和采用的评审做法。

来源中的 Asana 不是被作为产品功能案例展开，而是作为工程团队文化的上下文出现。文章强调团队应约定代码评审目标、用运行和本地开发环境补足 diff 阅读、尽快反馈作者，并在没有明确 bug 时默认批准。
