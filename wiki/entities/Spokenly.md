## Overview
[[Spokenly]] is presented as an AI voice-input tool that supports local custom configuration for transcription and post-processing.

## Current Profile
The source describes Spokenly as the author's main customizable fallback setup. In that configuration, the author uses [[Soniox]] as the transcription model and [[Grok4]] as the AI model for cleanup, producing stable and comfortable output.

## Key Characteristics
- Supports custom AI prompt configuration for voice-input cleanup.
- Can be configured with separate transcription and AI post-processing models.
- Serves as the author's local fallback alongside [[Typeless]].

## Evidence
- Custom prompt use: [[ai-yu-yin-shu-ru-gong-ju-ti-shi-ci]] lists Spokenly among tools suitable for user-defined AI cleanup prompts.
- Model stack: [[ai-yu-yin-shu-ru-gong-ju-ti-shi-ci]] says the author's Spokenly setup uses [[Soniox]] transcription and [[Grok4]] post-processing.
- Role in workflow: [[ai-yu-yin-shu-ru-gong-ju-ti-shi-ci]] frames Spokenly as a local custom fallback while [[Typeless]] supplies strong performance.
