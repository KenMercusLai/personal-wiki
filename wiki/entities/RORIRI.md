## Overview
[[RORIRI]] is the author of the source explaining LLM terminology through context management and action interfaces.

## Current Profile
Within this wiki, RORIRI appears as an AI commentator who connects practical agent tooling terms to a single architectural concern: how LLM context is shaped, polluted, compressed, retrieved, and connected to external actions. The source uses informal examples from coding agents, MCP, Skills, RAG, Memory, prompt caching, and Computer Use to build a practical taxonomy.

## Key Characteristics
- Explains LLM tooling concepts through the common problem of context management.
- Distinguishes prompt-level guidance from structured tool-call interfaces.
- Treats memory and RAG as related retrieval mechanisms.
- Argues for active context compression over passive summarization.
- Frames Computer Use as a packaging layer over lower-level agent action mechanisms.
