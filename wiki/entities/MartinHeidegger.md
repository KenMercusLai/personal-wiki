## Overview
[[MartinHeidegger]] is cited in the source as the philosopher whose hammer example shows how tools withdraw into use and become newly visible when they break.

## Current Profile
Within this wiki, Heidegger functions as the source's bridge from everyday tool use into object-oriented ontology and aesthetics. The article does not summarize his wider philosophy; it uses the hammer from Being and Time to show how an object can be both practically available and ontologically hidden.

## Key Characteristics
- Associated with the hammer example from Being and Time.
- Used to explain tool transparency during smooth practical activity.
- Used to explain breakdown as a moment when an object stands out from its practical background.
- Serves as the conceptual entry point for [[ObjectWithdrawal]] in the essay.

## Evidence
- Hammer example: [[cong-hai-de-ge-er-de-chui-zi-dao-yin-yu-de-xi-ju-xing]] describes a hammer becoming transparent while it is skillfully used.
- Breakdown salience: [[cong-hai-de-ge-er-de-chui-zi-dao-yin-yu-de-xi-ju-xing]] says a damaged hammer reveals a dimension hidden by ordinary tool use.
- Bridge role: [[cong-hai-de-ge-er-de-chui-zi-dao-yin-yu-de-xi-ju-xing]] moves from Heidegger's tool analysis into Harman's object withdrawal.

## Qualifications
The source is narrowly interested in Heidegger's tool analysis. It does not cover Heidegger's biography, politics, broader ontology, or the scholarly disputes around his work.
