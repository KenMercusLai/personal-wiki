## Overview
[[Memox|memox]] is a software project by [[Leetao]] that was paused, restarted, and reduced to one retained function.

## Current Profile
The source presents memox as a concrete response to analysis-driven creative paralysis. After AI-supported research had helped persuade Leetao to abandon ideas, he revived the project and reports deleting about 80% of its code so that one core function remained. Its importance in the source is the shift from accumulating scope to restoring a small buildable artifact.

## Key Characteristics
- Revived after an earlier pause.
- Reduced by about 80% of its code according to its creator.
- Retained one core function.
- Used as an example of simplicity restoring creative momentum.

## Evidence
- Project revival: [[guo-qing-sui-bi-leetao]] says Leetao restarted the previously paused memox project.
- Scope reduction: [[guo-qing-sui-bi-leetao]] reports removing roughly 80% of the code and preserving one function.
- Creative role: [[guo-qing-sui-bi-leetao]] links returning to the project with the return of creative enjoyment.

## Qualifications
The source does not identify the retained function, product history, repository, users, platform, release state, or measurable outcomes. The percentage is a first-person estimate and does not by itself establish lower complexity, better usability, or product demand.
