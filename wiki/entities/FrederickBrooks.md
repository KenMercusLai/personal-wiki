## Overview
[[FrederickBrooks]] is the software-engineering thinker represented here through his “No Silver Bullet” distinction between essential and accidental complexity.

## Current Profile
In [[Piglei]]'s account, Brooks provides the conceptual vocabulary for separating the difficult design, specification, and testing of an interdependent conceptual structure from the work of expressing that structure in a particular implementation. The source uses that distinction to challenge claims that faster AI code generation eliminates software development's hardest problems.

## Key Characteristics
- Associated with the “No Silver Bullet” argument about the persistent difficulty of software development.
- Distinguishes essential conceptual complexity from accidental implementation complexity.
- Treats specification, design, and testing of conceptual structures as harder than their mechanical expression.
- Provides a framework later practitioners can use to evaluate AI coding claims without denying genuine implementation gains.

## Evidence
- Complexity distinction: [[kai-fa-ruan-jian-huo-jian-zao-mi-gong-piglei]] attributes the essential-versus-accidental framing to Brooks's “No Silver Bullet.”
- Conceptual structure: [[kai-fa-ruan-jian-huo-jian-zao-mi-gong-piglei]] quotes Brooks on software entities as precise, interdependent arrangements of data, relationships, algorithms, and function calls.
- AI-era application: [[kai-fa-ruan-jian-huo-jian-zao-mi-gong-piglei]] uses the framework to argue that rapid agent implementation does not establish that a worthwhile product has been conceived or verified.

## Qualifications
This profile is based on one practitioner's Chinese-language discussion and short translated excerpts rather than the complete original paper, Brooks's wider body of work, or software-engineering scholarship. The source's application of the distinction to current AI agents is Piglei's interpretation, not a claim Brooks made about those systems.
