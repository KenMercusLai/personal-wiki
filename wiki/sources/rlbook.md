## Key Claims
- [[MultiArmedBandit]] isolates exploration versus exploitation by removing state transitions and delayed credit assignment; sample averages suit stationary rewards, while constant step sizes track nonstationarity by discounting older observations.
- A [[MarkovDecisionProcess]] defines state so the present contains the information needed to predict the next reward and state; partial observability or state aliasing breaks that convenient representation without making learning impossible.
- Dynamic programming uses a known environment model to compute expected Bellman updates over possible successors, whereas [[MonteCarloEstimation]] and [[TemporalDifferenceLearning]] learn from sampled experience without that complete distribution.
- [[TemporalDifferenceLearning]] bootstraps from the next estimate and can update online; Monte Carlo waits for sampled returns, while n-step methods interpolate between the two.
- On-policy methods evaluate or improve the policy generating experience, whereas off-policy methods require behavior-policy coverage and correction when learning about a different target policy.
- [[FunctionApproximation]] replaces a separate table entry per state with a parameterized value or policy, enabling generalization while coupling errors across states and introducing semi-gradient, distribution, stability, and partial-observability limits.
- [[PolicyGradient]] directly changes action probabilities using sampled return-weighted score gradients; subtracting a state-dependent baseline leaves the expected update unchanged and can reduce variance when the baseline is chosen well.
