## Summary
[[AlexandraPhelan]] describes an [[AcademicResearchWorkflow]] that divides research work among [[Zotero]], [[Obsidian]], and [[Pandoc]]. Zotero stores source metadata, PDFs, annotations, citekeys, and citation styles; Obsidian imports source-linked literature notes, supports bidirectional synthesis and Markdown drafting, and can track publication projects; Pandoc converts citekey-bearing drafts to DOCX for collaboration or submission. The workflow favors durable plain-text drafting and flexible citation formatting, but it is a practitioner configuration with a learning curve rather than a comparative evaluation.

## Key Claims
- A two-application research environment can separate source and citation management in [[Zotero]] from linked-note synthesis, drafting, and project tracking in [[Obsidian]].
- Zotero browser connectors and manual entry collect bibliographic metadata, while its PDF reader keeps highlights and notes attached to the source record.
- Better BibTeX can generate stable citekeys and an automatically updated BibTeX library; the source uses an author-year convention such as `Carter_2022`.
- Obsidian's Zotero Integration can create one literature note per reference containing metadata, a Zotero link, annotations, and color-coded note categories.
- The `@citekey` naming convention distinguishes a double-bracketed internal literature-note link from a Pandoc citation such as `[@Stephens_2021]`.
- [[Pandoc]] citations defer formatting until export, allowing one Markdown manuscript to switch among journal styles through a bibliography file and optional CSL configuration.
- Dataview can index literature notes, while Pandoc Reference List can expose formatted references and citekey completion during drafting.

## Key Quotes
> "The synthesis of my readings and annotations into new notes that help me draft manuscripts is a critical part of generating ideas and writing papers." - on notes as the bridge from reading to writing.

> "There is a steepish learning curve if you have limited programming experience" - on the workflow's adoption cost.

## Contradictions
- [[ReadingNoteWorkflow]] uses "literature note" for brief, selective restatements that feed permanent notes, whereas this source uses the same label for a comprehensive per-reference import of metadata, highlights, and annotations. These are compatible stages only if the imported note is treated as source material rather than as finished synthesis.
- The source recommends Zotfile for consistent PDF renaming but notes that it no longer moves attachments because of Zotero iOS compatibility; this is a historical 2023 configuration rather than a claim about current plugin support.
- No direct contradiction exists with [[Obsidian]] or [[PersonalKnowledgeManagement]]. The source strengthens their output-oriented framing but supplies personal experience rather than comparative reliability, productivity, or learning evidence.
