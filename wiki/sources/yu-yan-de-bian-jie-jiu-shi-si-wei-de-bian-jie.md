## Summary
这篇未署名随笔借“语言的边界就是思维的边界”讨论人类与大语言模型的[[LinguisticExpressiveBoundaries|表达边界]]：模型把文本切成 token、映射为向量并学习续写分布，因此其训练材料、提示词和标注偏好会共同塑造可生成内容与文风。文章进一步把科研创新理解为向人类概念系统增加新词，并把模型生成文本反复用于训练与[[ModelCollapse|模型坍塌]]联系起来；但“一个概念必须对应一个专用 token”以及“温度随机性必然让递归训练不断增熵”的机制解释都过于绝对，文中也没有给出所称论文的题名或实验信息。

## Key Claims
- [[LanguageModeling]]以 token 序列、向量表示和矩阵计算为基础，生成能力受到词表与训练材料影响。
- 人与模型能表达什么都受已学习材料约束，新的科学发现和概念创造则扩展可讨论与可思考的范围。
- 训练文本、系统提示词和人工标注会塑造模型文风，常见结果包括固定转折句式、破折号、比喻、赞美和情感建议等可辨认模式。
- 模型生成内容常被用于复述、翻译和概括，因为这些任务主要重组已有材料，而科研与探索要求形成新的概念区分。
- 文章称把模型生成文本持续回灌训练会导致性能回归，并把这一[[ModelCollapse|退化]]归因于采样温度引入随机性、迭代增加熵。

## Key Quotes
> “大模型所学的，就是大模型所可以表达的。同理人所学的，就是人可以表达的。” - 文章将模型训练边界类比为人的表达边界。

> “当提出新的概念，用来解决问题时，也是在给人的知识拓展边界。” - 文章把概念创造视为扩展认知词表。

## Connections
- [[LinguisticExpressiveBoundaries]] - 中心论点把语言、已学材料与可表达内容的边界联系起来。
- [[LanguageModeling]] - token 化、向量表示、注意力计算和续写是文章采用的模型工作框架。
- [[Embeddings]] - token 被映射成向量后参与模型计算。
- [[AttentionMechanism]] - 文章以注意力论文作为矩阵运算架构的例子。
- [[TextGenerationSampling]] - 温度会改变生成时对下一个 token 的抽样，但不等同于训练数据质量的完整机制。
- [[SemanticAblation]] - 固定句式和高概率风格与模型输出趋同、细节被抹平的风险相邻。
- [[BreakthroughKnowledge]] - 新发现和新概念被描述为扩展既有知识与语言边界。
- [[ModelCollapse]] - 文章声称递归使用模型生成数据会使后续模型退化。

## Contradictions
- 词表限制模型直接选择的 token 单元，但现代子词或字节级 token 可以组合出未作为单一词元收录的新词、名称和字符串；“没有某个词的 token 就无法说出这个词”并不普遍成立。
- 一个概念不需要对应一个专用 token。模型可以用多个 token 组合描述新概念，也可能在有现成术语时仍缺乏可靠理解；训练覆盖、组合泛化、上下文与工具使用都使“学过即能表达、没学过即不能表达”只能作为近似。
- 生成文本的模板化可能受训练分布、后训练偏好、提示词、解码设置与产品层策略共同影响；文章列出的语言习惯是观察，没有频率、对照模型或因果实验。
- 文中没有标明所称递归训练论文。即使模型生成数据可能造成分布收缩或误差累积，也不能仅凭采样温度推出“熵值必然不断增加”或最终必然得到无意义文本；筛选、真实数据配比、任务与训练方法都是未处理变量。
