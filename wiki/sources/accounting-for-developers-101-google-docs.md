## Summary
John McKee and Tom Mornini introduce double-entry accounting as a compact conceptual system that software developers can use when writing code that tracks money. The fragment argues that developers often misunderstand accounting until they see it as an elegant software design technique, and it criticizes many modern accounting packages for behaving like business-document databases that merely produce accounting reports. The source ends mid-sentence after noting that double-entry accounting predates Luca Pacioli's 1494 description by at least two centuries, so its historical argument is incomplete.
