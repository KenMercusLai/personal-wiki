## Summary
[[BenedictEvans]] argues that modern car dashboards resemble late feature phones: individual electronic features may work, but their accumulated buttons, icons, warnings, and custom firmware have overloaded the old interface model. The article uses [[AutomotiveInterfaceTransition]] to connect in-car UX, sensor fusion, software-platform replacement, and autonomy, arguing that a car should increasingly decide when it has enough information instead of asking the driver a string of warning-light questions.

## Key Claims
- Car safety and convenience features have accumulated into a dashboard interface that exposes too many separate icons, buttons, and alerts instead of solving the driving job directly.
- The deeper problem is not only weak automotive UX, but an overloaded interface model that needs inversion: many visible controls should disappear under a new software platform.
- The pattern mirrors other electronics categories where feature-by-feature firmware turns into a fragile custom computer and is eventually replaced by a real software platform, often from a different company.
- Sensor fusion is a necessary technical step for autonomy because one computer builds a unified model from many vehicle sensors, but it does not by itself answer the user-interface question.
- A useful design rule is that computers should not ask users questions they can answer themselves; many warnings are effectively questions that a safer car should resolve through action.
- The transition from warnings to partial autonomy is risky because systems that drive themselves until they suddenly do not can leave humans badly positioned to intervene.
- Evans frames semi-autonomous car UI as a potential Apple opportunity because it requires deep interface thinking before fully autonomous, no-control vehicles remove most in-car interaction.

## Key Quotes
> "Like a melting iceberg rolling over, you need to invert the interface model." - Evans on replacing visible feature accretion with a new platform.

> "The end-point is to have no interface at all." - Evans on Level 5 autonomy.
