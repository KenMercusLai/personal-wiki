## Summary
文章面向非专业开发者，以 [[Replit]] 样例、[[LangChain]]、OpenAI API 和 FAISS 演示如何让大语言模型基于用户提供的文本回答问题。其核心流程是切分文档、生成嵌入、向量检索相关片段，再把片段、问题和对话历史交给模型；文章进一步将 LangChain 视为连接模型、数据、记忆、提示与工具的中间开发层。

## Key Claims
- 基于私域数据的问答可以把模型的语言理解与表达能力同外部知识解耦，使模型回答训练数据截止时间之后或组织内部的信息。
- 一个基础的 [[RetrievalAugmentedGeneration]] 流程包括文档切片、片段嵌入与向量存储、问题嵌入与相似度检索，以及带检索上下文的答案生成。
- 分块大小影响检索上下文的取舍：过小可能遗漏关键信息，过大可能引入无关内容。
- LangChain 的加载器、文本切分器、向量存储、链、提示模板、记忆和代理等模块降低了组合大模型应用组件的门槛。
- Replit 托管样例让初学者无需配置本地环境即可完成演示，但仍需管理 API 密钥、上传数据、构建向量索引并运行程序。
- 文章主张自然语言提示将部分后端行为从过程式实现转向结果描述，并据此看好 LLM 中间工具层；这一判断是早期生成式 AI 阶段的产品观点。

## Key Quotes
> “将ChatGPT自身的语言理解和表达能力与数据进行解耦” — 作者概括私域数据问答的产品目标

> “把用户当前输入的问题、之前的历史问答和找到的片段作为上下文” — 作者描述生成答案时传给模型的信息
