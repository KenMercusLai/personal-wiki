## Summary
This captured [[BJFogg]] page introduces the [[FoggBehaviorModel]] as a practical framework for designing and diagnosing behavior change. It argues that behavior occurs only when motivation, ability, and a prompt converge at the same moment, and that motivation and ability can compensate for each other. The source also positions the model inside Fogg's broader [[BehaviorDesign]] system, his [[BehaviorDesignLab]] work at Stanford, and the book [[TinyHabits]].

## Key Claims
- A behavior occurs when motivation, ability, and a prompt converge at the same moment.
- Failed behavior can be diagnosed by looking for the missing element among motivation, ability, and prompt.
- The model organizes behavior change into motivation subcomponents, simplicity factors for ability, and prompt types.
- Motivation and ability have a compensatory relationship: high motivation can offset low ability, while low motivation requires higher ability.
- The model is framed less as abstract psychology and more as a practical design tool for creating beneficial behavior change.

## Key Quotes
> "three elements must converge at the same moment" - core model statement.

> "Motivation and Ability can be traded off" - explanation of the compensatory relationship.
